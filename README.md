# RIIZE — LONG WAY HOME

이유영의 독립 A&R·음반기획 웹 포트폴리오. 가상의 5곡 겨울 스페셜 EP 제안입니다.

> 너에게 닿아, 나로 돌아오다.

**[웹 포트폴리오 열기](https://yooyoung101-blip.github.io/riize-long-way-home/)**

- **HOME**: 나를 설명할 필요가 없는 관계.
- **LONG WAY**: 타인의 기대를 지나 나다운 모습을 알아가는 시간.
- **WINTER**: 작은 배려와 체온이 선명해지는 계절적 감각.

112 BPM 팝 R&B 타이틀을 중심으로 해방·발견·장난·친밀·신뢰의 감정 흐름을 설계했습니다. 음악·보컬·퍼포먼스·MV·패키지·발매 캠페인·일정·예산을 담았습니다.

2026-10-08 개편에서는 **SAME SPACE / 같은 여백**을 기획안 전체의 시각 규칙으로 만들었습니다. 기존 《Love 119》의 여섯 인물 사진을 분리된 프레임으로 재구성하고, 트랙과 MV의 단계에 따라 하단선이 이어지는 방식을 표지·접지·티저까지 반복합니다. 기존 사진을 새 촬영물로 표시하지 않습니다. 데모 심사의 수정·보류 판단, 캠페인의 제안 수량·채널, 제작 승인 역할과 대안도 보강했습니다.

## 저장소 파일

| 파일 | 용도 |
|---|---|
| `index.html` | 포트폴리오 본문과 이미지 구성 |
| `styles.css` | 에디토리얼 디자인·모바일 반응형·인쇄 스타일 |
| `app.js` | 트랙·MV 장면·패키지·목차·예산 상호작용 |
| `assets/` | 사진 8장, Anton 웹폰트와 폰트 라이선스 |
| `check.mjs` | 내부 링크·파일·핵심 상호작용·예산 산식 검증 |
| `.nojekyll` | GitHub Pages 정적 배포 설정 |
| `SOURCES.md` | 리서치·사진 출처와 기획 가정 |

설치나 빌드 없이 `main / (root)`에서 게시합니다. 2026-09-30에는 모바일 읽기 동선·CD 시안·음악 및 일정 정합성을 보완했습니다. 2026-09-29 개편부터 CSS·JavaScript·이미지·폰트를 별도 파일로 분리했습니다. `index.html`만 내려받으면 전체 사이트가 복구되지 않으므로 저장소 전체를 사용합니다. 과거 단일 HTML과 ZIP은 이전 디자인입니다. 편집 전 최신 커밋과 해당 파일 SHA를 확인합니다.

로컬 코드 검증: `node check.mjs`. 이 검사는 실제 브라우저 렌더링을 대체하지 않습니다.

## 주요 기능

- 5개 트랙 선택: 사진·감정·사운드·보컬·데모 심사 기준 전환. 모바일에서는 가로 카드를 넘겨 선택. 방향키·Home·End 키 지원. 제안곡 오디오 재생 기능은 없습니다.
- 5개 MV 장면 선택: 구도 레퍼런스·타임코드·창작 콘티 전환.
- 패키지 펼치기: 포토북·CD·감정 기록용 포트레이트 카드와 ‘6개 분리 프레임 → 공동 프레임’ 접지의 디지털 시안.
- 여섯 멤버의 사진을 새 프레임 규칙으로 조합한 첫 화면·1:1 키비주얼·9:16 티저 디자인 시안.
- 전 구간에서 열 수 있는 전체 목차. Escape로 닫은 뒤 버튼에 포커스가 돌아옵니다.
- 세 가지 핵심 판단 요약과 상세 바로가기, 읽기 진행률.
- 비교표·일정표·예산표 가로 스크롤 및 키보드 접근, 작은 화면의 스크롤 안내.
- 초도 수량 5,000~30,000장 시뮬레이션: 고정비 180,000,000원 + 수량 × 6,000원 + 소계의 10% 예비비.
- 기존 곡 영상 및 리서치 출처 링크.

## 기획과 자료의 범위

실제 발매·데모 수급·아티스트 협의·회사 승인이 없는 개인 기획안입니다. 곡명·템포·길이·보컬 배치·일정·예산은 제작 가정이며 실제 성과나 확정 계획이 아닙니다. 공개된 아티스트 사진은 기존 활동 레퍼런스입니다. 신규 촬영물이나 이용 허락을 받은 자료로 표시하지 않았습니다. 상세 출처와 확인 범위는 [SOURCES.md](SOURCES.md) 및 웹페이지 마지막 장에 있습니다.

`noindex`는 검색엔진에 색인 제외를 요청하는 메타데이터입니다. 공개 페이지의 접근을 제한하지는 않습니다.
